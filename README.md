Radiance Cascades Compared to Unity’s Standard Global Illumination Methods

DIGRA Conference — Experimental Setup

This repository contains the experimental materials for the research paper “Comparative Evaluation of Real-Time Global Illumination Methods in Unity URP.”

The project evaluates Radiance Cascades against Unity’s standard global illumination methods, focusing on real-time rendering performance and visual quality. It provides the datasets, generated figures, and visual comparison recordings used to support the experimental analysis.

My Contribution

My contribution to this research project includes preparing and organizing the experimental materials used for the comparative evaluation of real-time global illumination techniques in Unity’s Universal Render Pipeline (URP).

The repository serves as a reference for the performance measurements and visual results collected during the experiments.

Repository Contents
Raw Performance Data: FPS and frame-time datasets collected during the experiments.
Generated Figures: Visualizations and plots used in the research paper.
Visual Comparisons: Rendered video recordings demonstrating the visual differences between the evaluated global illumination methods.

Research Objective

The objective of the experiment is to compare Radiance Cascades with Unity’s standard global illumination methods in terms of real-time rendering performance and visual output. The collected performance data and rendered comparisons provide the basis for analyzing the strengths and limitations of the evaluated techniques.
